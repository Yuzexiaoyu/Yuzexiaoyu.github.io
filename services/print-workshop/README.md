# 雨泽小鱼的工坊 · 本地版

## 启动

双击项目根目录的 `启动工坊.cmd`，等待窗口打印地址后打开：

- 工坊：<http://127.0.0.1:13135/prints/>
- 独立本地后台：<http://127.0.0.1:13135/admin/prints/>

需要 Python 3.10+；使用项目已有的 `hugo.exe` 构建，不需要安装 pip 依赖。关闭启动窗口或按 Ctrl+C 可停止服务，已保存内容仍保留。每次重新运行会重新构建页面。

也可在项目目录执行：

```powershell
python services/print-workshop/server.py --build --demo
```

首次启动会加入可选“扭纹花器”、现货“青绿扭纹花器”，以及初始色卡。两件条目均有具体标题和介绍，可在后台修改。它们直接使用正常的展示、配置和报价流程，可在后台编辑或下架。删除后再次启动不会自动补回。

## 管理内容

1. 在“公共色卡”维护实际可用的颜色名称、预览色值和对应材质。可选物品的材质跟随所选颜色，在详情及清单中同步更新。
2. “新建内容”中选择可选或现货，填写标题、介绍，上传图片和视频。第一张图片作为封面，可更换封面或移除图片。
3. 可选条目勾选可用颜色，设置 15% 和 100% 填充时的价格与重量；顾客只通过滑块调整填充比例，百分比只读显示。其余填充比例在两端之间线性计算。报价四舍五入到整数元，重量保留最多两位小数（克）。重量尚未提供时可留空；上架时若填写重量，需要同时填写两端。
4. 现货填写固定重量（克）和材质，无需配置颜色或填充。固定售价可留空，顾客会看到「敬请期待」，填入售价后才显示联系购买按钮。现货材质单独保存在物品记录中。两个栏目均需至少一张图片；视频和 GLB 模型均为选填。有视频时进入详情页默认静音自动播放第一个视频。桌面使用原生控件，手机在视频下方显示播放、进度和声音控制；无视频时默认展示第一张图片。
5. 选择草稿、上架或下架后保存。未上架内容不会出现在顾客目录中。
6. 顾客可从详情页查看联系二维码与 QQ 号，并复制选购清单。可选清单仅包含商品、材质、颜色、填充比例和报价；现货清单仅包含商品、材质和报价。

当前联系弹窗使用裁出的 QQ 码并显示 QQ 号 `2045757235`；号码统一定义在 `assets/ts/workshop-shared.ts` 的 `CONTACT_QQ`。后台仅保留内容管理与公共色卡，联系二维码随公开工坊数据一同导出发布。

桌面编辑器在同一屏内显示三个区域：左侧标题与介绍，中间价格、重量和颜色，右侧图片、视频及 GLB／3MF 文件。无需切换编辑页签，编辑窗口与背景均不滚动，保存和取消固定在底部。图片与色卡较多时在各自区域翻页，跨页勾选的颜色会保留。

初始可选条目有两张不同配色图片。详情使用响应式正方形展示区，图片、视频、3D 预览始终占据相同尺寸；图片和视频完整缩放显示。所有媒体统一通过展示区下方的一组按钮直接切换，顺序为视频、图片、3D 预览，不再显示缩略图。多个同类媒体依次显示“视频1、视频2”或“图片1、图片2”，单个媒体不编号；按钮在窄屏自动换行。现有两件本地条目共用一段 1 秒 WebM 测试画面，用于测试播放和媒体切换，可在后台替换或移除。当前可选条目的临时重量端点为 60 克（15%）和 180 克（100%），50% 填充显示 109.41 克，可在后台替换为实际数值。

现有示例色卡及现货的材质暂填 PLA，可在后台替换为实际材质。旧数据未填写材质时显示破折号；现货切换为可选后，清除独立材质，改为读取所选颜色的材质。

每次点击视频按钮都会从头播放。可选条目带模型时，点击颜色会直接切换到 3D 并应用当前颜色。3D 默认距离为自适应基准的 150%，可拉远至 400%，缩放灵敏度为 0.1；重置恢复默认视角。查看器顶部的内置进度条已隐藏，保留现有加载提示。

图片支持 PNG、JPG、WebP，单张最大 12 MB，单条内容最多 12 张。视频支持 MP4、WebM、MOV，单个最大 64 MB，单条内容最多 6 个。模型最大 64 MB；GLB 须自包含，当前离线预览不接收 Draco、Meshopt 或 KTX2/Basis 压缩资源。色卡被内容引用时不能直接停用，应先取消相关商品的勾选。

3MF 可以作为原件保存，但暂不自动转换成 GLB。代表性 Bambu Studio 样本尚未提供，兼容性验证待补。原件没有顾客下载入口；浏览器预览必需的 GLB 会发送到浏览器。

## 本地范围与保存位置

- 服务固定监听 `127.0.0.1`，只允许本机 Host；不开放局域网或公网访问。
- 后台 HTML 在 `services/print-workshop/admin.html`，不属于 Hugo 的 `content` 或 `static`，不会被构建成公开页面。
- 顾客页面没有管理入口。本地管理写入使用会话 Cookie、同源检查和每次启动更新的请求令牌。
- 本地后台不设独立账号密码；可以访问这台电脑的用户能够打开后台。
- 数据保存在 `.local/print-workshop/data/workshop.sqlite3`；上传文件在同目录的 `files/`。这些路径已排除 Git 跟踪。
- 备份时先关闭服务，再复制整个 `.local/print-workshop/data` 文件夹；恢复时在服务停止状态下恢复该文件夹。
- `.local/print-workshop/site` 是可重新生成的页面；清除浏览器缓存不会删除数据库。
- 删除内容后未引用的上传文件暂保留在本机，不自动清理。

## 发布到现有网站

线上工坊使用静态公开目录，本地管理后台仍只在当前电脑运行。管理后台保存内容不会立即改变线上页面；修改完成后，在项目目录执行：

```powershell
python services/print-workshop/export_public.py
```

该命令更新 `static/workshop/catalog.json` 和 `static/workshop/media/`，仅包含已上架内容、对应预览图片／视频／GLB、公共联系二维码。草稿、下架内容、3MF 原件、数据库和管理页面不导出。重新导出会移除已下架内容及不再引用的公开素材。

检查导出结果后，将 `static/workshop/` 的变更提交并推送到现有 `master` 分支；GitHub Actions 会上传图片、视频和 GLB 到 R2，把目录中的工坊媒体地址重写为 CDN，再发布到 `https://yuzexiaoyu.space/prints/`。发布副本使用静态数据，本地启动脚本使用 `workshop-local` 配置连接实时本机接口。

## 当前边界

没有在线支付、购物车、多件数量、数字文件出售或自动 3MF 转换。真实商品、图片、价格、色卡、QQ 二维码由站主补充。移动端已做浏览器模拟检查，尚未在实体手机上验收；本地回环服务不能直接在另一台手机上打开，公开页面可通过网站域名访问。

## 验证

```powershell
python -m unittest discover -s services/print-workshop -p test_server.py -v
```

测试使用独立临时数据库和文件，不修改实际工坊数据。实施与验证证据见 `docs/print-workshop-implementation.md`。

页面构建完成后，可使用 Node.js 运行入场动画生命周期检查：

```powershell
node --test services/print-workshop/test_intro.cjs
```

桌面顶部为两个独立模块：左侧工坊标识，右侧返回博客，中间保持透明；手机保留紧凑导航。工坊与文章使用同一套站内导航跃迁：点击时加速至 40，导航完成后调用相同的减速逻辑，350 毫秒后平滑恢复常速。手机沿用现有轻量画布并接入同一接口。模块渐入与跃迁同时进行，不隐藏整页、不锁定操作，也不等待跃迁结束；模块动画不控制背景速度。直接刷新与文章一样不额外触发导航跃迁。

工坊脚本与线上目录数据并行请求。卡片和详情媒体就绪后立即开始渐入，首批卡片按 45 毫秒错开，卡片动画为 320 毫秒。详情优先加载当前媒体，并在网络条件允许时后台解码相邻小图。后台打开时不会提前消耗，切回后继续；数据较晚到达时，不附加固定等待。详情的媒体、标题、介绍及配置区分别出现，不叠加父级透明度。系统开启“减少动态效果”时仅使用 260 毫秒无位移淡入，保留短暂前后层次。具体节奏位于 `assets/ts/workshop-intro.ts` 的 `show`、`playWhenVisible` 与 `refresh`。目录直接从栏目标签和作品开始；详情页按视频、图片、3D 预览排序，有视频时默认视频，否则默认图片，点击 3D 或选择颜色时才加载模型。

`scripts/verify-workshop.cjs` 检查实际浏览器中的桌面／手机目录、详情、颜色报价、入场曲线、慢加载及视频切换。先启动静态预览服务，再运行 `node scripts/verify-workshop.cjs http://127.0.0.1:13136`。需要 Playwright 和 FFmpeg；可用 `PLAYWRIGHT_MODULE` 指向已有 Playwright 包、`WORKSHOP_QA_VIDEO` 指向已有 WebM 测试片段。视频测试仅拦截测试浏览器的目录响应，不写入实际条目。

`node scripts/verify-workshop-editor.cjs http://127.0.0.1:13135` 检查桌面编辑器的单屏布局、滚动锁定、关闭图标及保存交互。使用浏览器内隔离的后台 API 数据检查多素材、跨页选色与现货字段，不修改实际条目。
