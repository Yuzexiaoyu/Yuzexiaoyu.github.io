## 已确认执行的布局

沿用现有控件和视觉样式，将移动端详情组织为展示区、紧凑配置区与底部操作栏。颜色和填充比例直接出现在同一配置区；材质、重量等信息紧凑排列；长介绍放在主要配置之后。保留现有底部报价与联系入口。目标是在常见手机尺寸下让主要配置尽量一屏可用，小屏仅需少量滚动。

- 不修改 `assets/scss/_print-workshop.scss` 等桌面／共享样式，不改现有按钮、配色、字体与圆角，不改共享模板和业务交互来实现本次布局。
