# 站内动效约定

站内动效统一按完整节奏播放。来访设备或浏览器开启「减少动态效果」时，桌面端和移动端仍使用同样的触发条件、关键帧、位移和时长。

这一约定覆盖页面入场、卡片交互、专题详情、购物车、媒体滑动、阅读器翻页和目录平滑滚动。新增 CSS 与 JavaScript 动效直接使用相应功能的正常播放逻辑。

## 验证方式

回归检查分别模拟浏览器开启和关闭「减少动态效果」，核对两种设置下的播放轨迹、时长和结束状态。

常规样式和动效微调默认跳过截图验证。调整尺寸、时长、位置或增删装饰元素时，直接核对 DOM、计算样式或交互测试结果即可。仅在用户明确要求截图，或有具体的渲染问题需要通过截图判断时，才截图。
